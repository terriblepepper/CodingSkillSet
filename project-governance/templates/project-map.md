# 项目事实与维护导航

本页需根据当前项目源码核实填写；尚未调查的内容明确标记未核实，不沿用其他项目事实。

## 技术与入口

记录从依赖配置、运行入口和部署配置确认的语言、运行环境、框架及正式命令。

## 职责与依赖

按入口、业务编排、领域、基础设施整理模块职责；列出关键调用链、允许的依赖方向与既有边界检查。
指出需保留的权限、隔离、事务、状态机、幂等、取消、资源释放与兼容契约。

## 正式文档与测试导航

将改动主题映射到现有正式文档与测试入口，注明测试隔离和清理机制。
具体修改时依据证据选节点，不把测试文件列表当作每轮全量命令。

## 核验信息

记录核验日期与源码入口；不固化易变化的文件数、表数、接口数，不写秘密、用户数据或排查流水。
